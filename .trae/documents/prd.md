# OmniClip - 智能剪贴板管理器 PRD

## 1. 产品概述

### 1.1 产品定位
OmniClip 是一款完全离线运行的跨平台桌面智能剪贴板管理器，专注于安全、高效的本地剪贴板历史记录与快速检索能力。

### 1.2 目标用户
- 需要频繁复制粘贴的开发者、设计师、文案工作者
- 对数据隐私有高要求、不希望剪贴板内容上传云端的用户
- 需要快速查找历史复制内容的专业用户

### 1.3 核心价值主张
**"你的剪贴板，永远只属于你"** - 100% 本地离线，零网络请求，数据加密存储，极速搜索体验。

## 2. 功能需求

### 2.1 核心功能

#### F1: 自动剪贴板历史记录
- **功能描述**: 自动监听并记录剪贴板变化
- **支持类型**:
  - 纯文本 (plain text)
  - 富文本 (RTF/HTML)
  - 图片 (PNG/JPEG/GIF)
  - 文件路径列表 (仅记录路径，不复制文件)
- **记录频率**: 基于 OS 事件钩子（优先），降级为 500ms 轮询
- **重复检测**: 相同内容不重复记录，更新最近使用时间

#### F2: 极速全文模糊搜索
- **功能描述**: 对所有历史文本建立本地索引，支持快速检索
- **搜索能力**:
  - 模糊匹配 (fuzzy matching)
  - 拼音搜索 (中文拼音支持)
  - 中英文混合搜索
  - 子串匹配
  - 倒排索引加速
- **性能要求**: 万级记录搜索响应 < 50ms

#### F3: 星标收藏系统
- **功能描述**: 用户可收藏重要剪贴板片段
- **功能点**:
  - 一键星标/取消星标
  - 星标项目独立展示区域
  - 星标内容永不自动清理

#### F4: 多标签分类
- **功能描述**: 为剪贴板条目添加自定义标签
- **功能点**:
  - 创建/编辑/删除标签
  - 标签颜色自定义
  - 按标签筛选历史记录
  - 标签搜索联想

#### F5: 悬浮窗一键粘贴
- **功能描述**: 半透明悬浮窗，点击条目直接粘贴到当前光标位置
- **交互特性**:
  - 无边框透明窗口
  - 始终置顶 (always on top)
  - 点击外部自动失焦隐藏
  - 键盘导航支持 (↑↓选择, Enter粘贴, Esc关闭)
  - 毛玻璃视觉效果

#### F6: 本地安全存储
- **功能描述**: 所有数据本地加密存储
- **技术方案**:
  - SQLite 数据库存储
  - AES-256 加密
  - 图片以本地文件存储，数据库仅存路径
  - 可配置数据保留策略（自动清理过期非星标内容）

#### F7: 系统托盘集成
- **功能描述**: 系统托盘常驻，提供快速操作入口
- **功能点**:
  - 托盘图标显示运行状态
  - 右键菜单：打开主窗口、暂停记录、清空历史、退出
  - 全局快捷键支持（默认：Ctrl+Shift+V）

### 2.2 辅助功能

#### F8: 设置面板
- 快捷键自定义
- 最大历史条数设置
- 自动清理策略配置
- 数据导出/导入（JSON 格式）
- 忽略特定应用（可选）

#### F9: 历史记录管理
- 批量删除
- 按时间/类型/标签排序
- 搜索高亮显示
- 复制次数统计

## 3. 非功能需求

### 3.1 性能要求
| 指标 | 要求 |
|------|------|
| 启动时间 | < 1s |
| 内存占用 | < 100MB |
| 搜索响应 | < 50ms (万级记录) |
| 剪贴板监听延迟 | < 100ms |
| 安装包大小 | < 15MB |

### 3.2 安全要求
- **零网络请求**: 应用运行期间不发起任何 HTTP/WS 请求
- **数据加密**: SQLite 数据库使用 AES-256 加密
- **权限最小化**: 仅申请必要的剪贴板访问权限
- **敏感数据保护**: 可配置忽略密码字段等敏感内容

### 3.3 兼容性
- **Windows**: Windows 10/11 (x64)
- **macOS**: macOS 12+ (Intel & Apple Silicon)
- **Linux**: Ubuntu 20.04+, Fedora 35+, Arch (x64)

### 3.4 可用性
- 支持键盘全操作
- 符合各平台无障碍标准
- 高对比度主题支持

## 4. 技术栈

| 层级 | 技术选型 |
|------|----------|
| 框架 | Tauri v2 |
| 前端框架 | React 18 + TypeScript |
| 构建工具 | Vite |
| 样式方案 | Tailwind CSS + 自定义毛玻璃效果 |
| 状态管理 | Zustand |
| 本地数据库 | SQLite (via tauri-plugin-sql) |
| 剪贴板监听 | Rust arboard crate |
| 搜索索引 | tantivy (Rust) 或 SQLite FTS5 |
| 加密 | Rust aes-gcm crate |
| 打包 | Tauri bundler |

## 6. 数据模型

### 6.1 剪贴板记录 (ClipboardRecord)
```typescript
interface ClipboardRecord {
  id: string;           // UUID
  type: 'text' | 'image' | 'files';
  content: string;      // 文本内容或文件路径JSON
  thumbnail?: string;   // 图片缩略图路径
  title: string;        // 显示标题（文本预览）
  tags: string[];       // 标签ID列表
  isStarred: boolean;   // 是否星标
  copyCount: number;    // 复制使用次数
  createdAt: Date;      // 创建时间
  updatedAt: Date;      // 最后更新时间
  sourceApp?: string;   // 来源应用（可选）
}
```

### 6.2 标签 (Tag)
```typescript
interface Tag {
  id: string;
  name: string;
  color: string;        // 十六进制颜色
  createdAt: Date;
}
```

### 6.3 设置 (Settings)
```typescript
interface Settings {
  maxHistoryCount: number;
  autoCleanupDays: number;
  keepStarred: boolean;
  globalShortcut: string;
  ignoreApps: string[];
  theme: 'light' | 'dark' | 'system';
}
```

## 8. 风险与约束

| 风险 | 应对策略 |
|------|----------|
| Linux 剪贴板兼容性 | 使用 arboard 抽象层，测试各发行版 |
| 大图片存储性能 | 缩略图 + 原图分离存储，按需加载 |
| 搜索索引构建速度 | 增量索引 + 后台构建 |
| 跨平台窗口行为差异 | Tauri 窗口 API 封装，平台差异化配置 |
